Tra cứu tồn kho theo màu

Gõ tên màu hoặc mã (ví dụ brown nordic elm, bt1, hoặc brown nordic elm bt1) để xem ngay tồn kho — kể cả khi gõ thiếu chữ.

Nguồn dữ liệu tồn kho

Chưa có dữ liệu

Copy nguyên bảng tồn kho (giữ đúng cấu trúc file gốc) vào Google Sheet, đặt tên tab là Main (hoặc điền đúng tên tab bạn dùng). Công cụ tự tìm dòng tiêu đề chứa "Mã vật tư" nên không cần chỉnh sửa gì thêm. Link sẽ được ghi nhớ cho lần sau.

Dùng đúng file "Báo cáo tồn kho" xuất từ hệ thống — không cần chỉnh sửa gì trước khi tải lên.

⚠️ Dùng iPad (Chrome/Safari) mà nút chọn file không mở hộp thoại?

Đây là lỗi thường gặp của Chrome trên iPadOS khi mở hộp thoại chọn file trong 1 số trường hợp (site được thêm vào màn hình chính, hoặc chế độ duyệt riêng tư). Cách ổn định nhất trên iPad là dùng Google Sheet thay vì tải file trực tiếp:

  1. Mở file "Báo cáo tồn kho" (Excel) → tải lên Google Drive.
  2. Mở file đó bằng Google Sheets (chạm giữ → Mở bằng → Google Trang tính).
  3. Trong Google Sheets: Chia sẻ → chọn "Bất kỳ ai có link" → quyền Người xem → Sao chép link.
  4. Quay lại tab "Liên kết Google Sheet" ở trên, dán link vào, kiểm tra đúng tên tab, rồi bấm Tải dữ liệu.
