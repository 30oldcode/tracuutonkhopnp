Lập đơn hàng nhanh

Điền mã vật tư để tự nhảy tên sản phẩm và đơn giá theo dữ liệu tồn kho / bảng giá. Có thể thêm, xoá dòng và tự tính thuế, phí vận chuyển.

Nguồn dữ liệu (Tồn kho · Bảng giá · Phân loại màu)

Chưa có dữ liệu

Dùng đúng 1 Google Sheet có đủ 3 tab: TonKho (Mã vật tư / Tên vật tư / Đvt / Tồn cuối), BangGia (Loai_Van / Cap_Keo / Nhom_Mau / Do_Day_mm / Kho / Don_Gia_VND / Ghi_Chu) và PhanLoaiMau (Ma_Mau / HPL_Code / Phan_Loai) — đúng cấu trúc file gốc bạn đang dùng cho Apps Script tra cứu giá. Nếu thiếu tab bảng giá, công cụ vẫn tra được tên sản phẩm nhưng không tự tính được đơn giá.

Dùng đúng file Excel gốc có đủ 3 sheet TonKho (hoặc Main), BangGia, PhanLoaiMau — công cụ tự tìm đúng sheet theo tên, không cần chỉnh sửa gì trước khi tải lên.

⚠️ Trên iPad (Chrome/Safari) mà nút chọn file không mở hộp thoại, hoặc bấm "Tải dữ liệu" ở tab Google Sheet báo lỗi "Failed to fetch"?

Đây là do trang đang được mở trực tiếp từ file tải về (file://) thay vì từ một địa chỉ web — trình duyệt trên iPad chặn cả việc mở hộp thoại chọn file lẫn việc tải dữ liệu từ Google Sheet trong trường hợp này. Cách sửa: đưa file HTML này lên một địa chỉ web thật (ví dụ GitHub Pages, giống như trang tra cứu tồn kho), rồi mở qua link https://... đó thay vì mở file trực tiếp.
